# Elijah AI — SuperAdmin Frontend

Next.js 14 platform operations portal for Elijah AI super administrators.

For full setup, running, and testing instructions, please refer to:
👉 **[HOW_TO_RUN.md](HOW_TO_RUN.md)**

## Summary of Capabilities
- **Tenant Management:** Provision new contractor businesses with isolated database namespaces, automated phone number routing, and default role hierarchies.
- **Dynamic RBAC & Permissions:** Manage platform-level permissions and role templates.
- **Platform Analytics:** Real-time telephony traffic, AI minutes consumption, and revenue analytics across all contractor tenants.
- **System Health:** Live monitoring of external integrations (Retell AI, Twilio, Temporal, PostgreSQL).
